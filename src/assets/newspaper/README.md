# Newspaper margin illustrations

Six transparent pairs generated with the built-in image generation tool from
the approved Margin Stories concept sheet on 2026-10-17. Each PNG contains a
left scene in its left half and a right scene in its right half. The component
clips the two halves in CSS; the original generated PNGs are preserved.

| Asset          | Left scene                              | Right scene                                |
| -------------- | --------------------------------------- | ------------------------------------------ |
| `home.png`     | Snoopy resting under autumn leaves      | Woodstock on a fence post                  |
| `notes.png`    | Snoopy reading beside textbooks         | Woodstock writing with a geometry sketch   |
| `projects.png` | Snoopy coding and building a doghouse   | Woodstock with tools and a building plan   |
| `essays.png`   | Snoopy typing on the doghouse roof      | Woodstock with a letter and a falling leaf |
| `friends.png`  | Snoopy and Charlie Brown shaking hands  | Bird friends exchanging an envelope        |
| `about.png`    | Backpack, Mediterranean arch and plants | Woodstock, a map and Barcelona rooftops    |

Shared generation instruction: isolate the approved character scenes; remove
the sheet's labels, borders, paper and halftone; retain pale terracotta, warm
gray linework and ivory fills; place each complete scene in its own half of
a transparent 2:1 canvas, with a clear center gutter and no added objects.

Astro serves optimized WebP versions. These are decorative and intentionally
have empty alternative text. They appear only on the home and top-level
navigation landing pages in both languages. Edge dots are a separate CSS
layer and also appear on article pages.
