## Conceptes bàsics basic concepts

- **Bit/dígit binari**: Binary bit, the value is  `0`  or  `1`.
    
- **Byte**: usually  **8 bits**, which is the smallest addressable unit in common architectures.
    
- **Tipus de dades data type**: Determines the interpretation method, size (mida) and format (format) of the data, which is affected by language, operating system and hardware.
    
- **The same set of bits can have different meanings**: `01000111`  representable integers  `71`, can also represent ASCII characters  `'G'`.
    

Data type classification:

- **Escalars**: Integer, real number, character, Boolean, enumeration, pointer.
    
- **Especials Special types**: `void`.
    
- **Compostes/Agregades composite types**: array, struct, union.
    

## Notacions numèriques Base and conversion

- **Binari binary**: `0–1`.
    
- **Octal**: `0–7`;The courseware is written in C, such as  `010`  Represents decimal  `8`.
    
- **Decimal decimal**: `0–9`.
    
- **Hexadecimal**: `0–9, A–F`;The prefix is  `0x`, such as  `0xA = 10`.
    
- **1 octal digit = 3 bits; 1 hexadecimal digit = 4 bits**.
    
- **MSB — Most Significant Bit**: Most significant bit.
    
- **LSB — Least Significant Bit**: Least significant bit.
    

### Conversion method

- **integer: decimal → binary**:Continuous division by  `2`, remainder **Read in reverse order**.
    
- **Decimal: Decimal → Binary**: The decimal part is continuously multiplied by  `2`, take the integer part each time, **sequential reading**.
    
- **binary → decimal**: Multiply each by the corresponding weight and then sum; the weight on the right side of the decimal point is  $2^{-1},2^{-2},\ldots$.
    

Example:

- `97₁₀ = 01100001₂`, also an ASCII character  `'a'`.
    
- `53₁₀ = 00110101₂`, also an ASCII character  `'5'`, **character** `**'5'**` **not equal to numerical value** `**5**`.
    
- `0.3125₁₀ = 0.0101₂ = 1/4 + 1/16`.
    
- `11100110₂ = 0346₈ = 230₁₀ = 0xE6`.

### Representacions amb signe symbolic representation

- **Signe i magnitud original code**: The sign bit is represented separately from the absolute value.
    
- **Complement a 1 one's complement**: A negative number is obtained by inverting the corresponding positive number bit by bit.
    
- **Complement a 2's complement**: Negative numbers are represented by corresponding positive numbers **Negate and add 1** Get, commonly used in modern computers.
    
- **Biased representation Biased representation**:Stored value = actual value + bias, often used for floating point exponents.
    

to  **8-bit complement −23**  For example:

- In the complement code, the weight of the MSB is  **$-2^{N-1}$**, the remaining bits still have positive weights.
    
- For example  `11000111₂ = −128 + 64 + 4 + 2 + 1 = −57`.
    
- Fixed N-bit operations discard extra carries, but still need to check if the result occurred  **overflow**.
    

## Endianness byte order

**Endianness**:Multi-byte data in memory  **byte sort order**.

- **Big-endian Big-endian**: The high-order byte is placed at the low address, and the network byte order adopts this method.
    
- **Little-endian little endian**: The lower byte is placed at the lower address, x86 uses this method.
    
- What has changed is  **byte order**, not the bit order inside each byte.
    

Example: `1234₁₀ = 0x04D2`, according to memory address from low to high:

```
Big-endian：     04 D2
Little-endian：  D2 04
```

## Operations a nivell de bit Bit operations

### Shift Shift

- **Shift left / shift left** `**<<**`: Everyone moves to the left and fills in on the right  `0`.
    
- **Shift right / move right** `**>>**`: Everyone, move to the right.
    
- For unsigned numbers, shifting 1 bit to the left is equivalent to multiplying without overflow.  `2`; Shifting right by 1 bit is equivalent to dividing  `2`  Then round down.
    
- **Logical shift logical right shift**: Left side supplement  `0`.
    
- **Arithmetic shift Arithmetic shift right**: Left complement sign bit.

## Nombres reals real numbers

### Punt fix / Fixed-point fixed-point number

The decimal point position is fixed, with  **Qm.n**  expressed. According to this courseware agreement:

- `1 bit`: Sign bit.
    
- `m bits`: Integer part, excluding sign bit.
    
- `n bits`: Decimal part.
    
- **total number of digits = $1+m+n$**.
    
- **actual value = two's complement integer value ÷ $2^n$**.
    
- **step size / resolution = $2^{-n}$**.
    
- **range = $-2^m$  Arrive  $2^m-2^{-n}$**.
    

Example: **8-bit Q5.2**

- Total number of digits: `1 + 5 + 2 = 8`.
    
- Step size: `0.25`.
    
- Scope: **−32 ～ 31.75**.

## Error of precision

- **express limited ability**: Some decimal fractions loop infinitely in binary, such as  `0.1`, can only be stored approximately.
    
- **Arrodoniment / rounding rounding**: Replace with nearby representable value.
    
- **Truncament / truncation truncation**: Directly discard the low digits or decimal part.
    
- **Overflow**: The result exceeds the representable range of the format.
    
- The result of an operation may require more bits than the original operands.
    

Floating point operations do not necessarily satisfy:

- **Associativitat associative law**: `(a + b) + c`  may not equal  `a + (b + c)`.
    
- **Distributivitat distributive law**: `(a + b) * c`  may not equal  `a*c + b*c`.
    

**The order of operations, type conversions, and precision selection may change the final result.**

## Representacions per IA Representation in artificial intelligence

- **FP64, FP32, FP16, FP8**: Floating point format with different digits.
    
- **BF16**: 16-bit floating point format; different from FP16’s exponent and mantissa allocation.
    
- **INT8, INT4**: Low-digit integer format.
    
- **TF32**: NVIDIA specific computing format mentioned in the courseware.
    
- **Quantització / quantization quantification**: Map values to fewer representation levels, reducing storage and computational overhead, but may introduce errors.
    

Tradeoffs when choosing a format:

- **Rang**: Can express large and small numbers.
    
- **Precisió**: Can distinguish fine numerical differences.
    
- **Memòria i rendiment**: Memory usage and performance.
    

Example: `1750 亿参数 × 4 Bytes（FP32）≈ 700 GB`, here only the storage of the parameter itself is calculated.

## Characters and encodings

- **Char**: Used to represent characters, numeric characters and symbols.
    
- **ASCII**: 7-bit encoding, range  `0–127`, usually placed in 1 Byte.
    
- **ISO-8859-1 / Latin-1**: Single-byte encoding, which can represent 256 encoding positions.
    
- **Windows-1252 / CP1252**: Common old-style Western European encoding, which interprets partial positions differently than Latin-1.
    
- **Unicode**: Unified definition of characters and their code points; **UTF is a specific encoding method**.
    

Common UTF encodings:

- **UTF-8**: used for each Unicode code point  `1–4 Bytes`, ASCII compatible.
    
- **UTF-16**: Used per code point  `2 或 4 Bytes`.
    
- **UTF-32**: Used per code point  `4 Bytes`.
    

Note:

- **The number of bytes is not equal to the number of characters**.
    
- The encoding and decoding methods are inconsistent and garbled characters may appear.
    
- Multibyte text cannot be arbitrarily truncated or indexed by byte.
    
- **String string** with single  **character character** Different; C strings end with  `'\0'`  end.

## Punters / Pointers

**Pointer**: Stores the value of the memory address (adreça de memòria).

```
int num = 0x0503;
int *p = &num;
```

- `num`: The value in the variable, that is  `0x0503 = 1283`.
    
- `&num`:Variable  `num`  address.
    
- `p`: The address saved by the pointer, which is equal to  `&num`.
    
- `&p`: The address of the pointer variable itself.
    
- `*p`: Read the value of the pointed position, which is equal to  `num`, called  **dereference dereference**.
    

### Aritmètica de punters pointer arithmetic

- `**p + 1**` **Advance one element of the pointed type**, not a fixed advance of 1 Byte.
    
- `char*`: Normally forward  `1 Byte`.
    
- `int*`:If  `int`  If it is 4 Bytes, then move forward  `4 Bytes`.
    
- General rules: `p + k`  The address offset is  `**k × sizeof(*p)**`.
    
- Pointer arithmetic should be used within a valid array range.
    

## Tipus de dades agregades compound types

### Arrays and tensors

- **Array**: A set of elements accessed by index (íindex).
    
- In C/C++ arrays, the elements are of the same type and stored continuously.
    
- Example: `int a[5]`;if  `int`  is 4 Bytes, the array occupies a total of  `20 Bytes`.
    
- Can have one or more dimensions; **tensor**  It is a generalization of multi-dimensional arrays and is often used in machine learning.
    

Multidimensional arrays still need to be arranged into a sequence in memory:

```
矩阵：
A B C
D E F

Per fila / row-major：
A B C D E F

Per columna / column-major：
A D B E C F
```

- **C/C++**: Store by row.
    
- **Fortran, MATLAB, R**: Usually stored in columns.
    

### Structs

- Combine multiple fields together, each field can be of different types.
    
- **Each field has its own storage space and can retain values at the same time.**.
    
- **Padding padding bytes**: used for memory alignment, so the total size is not necessarily equal to the sum of the field sizes.
    

Courseware example:

```
int 4 B + char 1 B + padding 3 B + float 4 B = 12 B
```

### Unions

- multiple members **share the same memory**.
    
- Writing to a member overwrites the shared storage contents.
    
- Size needs to accommodate the largest member and meet alignment requirements.
    
- in the courseware  `int / char / float`  union is  `4 Bytes`.
    

**Struct: members occupy space respectively; union: members share space.**

### Classes and objects

- **OOP — Object-Oriented Programming**: Object-oriented programming.
    
- **Class class**: Combine data fields with methods for manipulating that data, and control access.
    
- **Object**: Instance of class (instància).
    
- For example  `string`  In addition to saving characters, the class also provides related operations; `char array`  Itself is just a character array.
